What the codebase says

Grounding Context

EDMissions already combines a recent-news feed, five-exchange research chat with saved notes, Campaign Studio with campus memory and text/HTML templates, tasks, and an ambient music player. Its product direction is deliberately personal: one enrollment leader, little ceremony, and a slightly rebellious visual voice.

The strongest gap is connective tissue. Useful information enters through the feed and Research Hub, but turning it into a campaign, task, or portable briefing still asks the user to move context by hand. The shortlist therefore favors small workflow bridges and deterministic quality checks over new integrations, prospect records, or predictive analytics.

Current recruitment platforms reinforce the value of events, appointments, actionable follow-up, audience-specific communication, and campaign measurement. Those patterns are useful here only after being reduced to a one-user scale.

I1

Signal → Workbench

Top pick

Give every feed article and saved research response a compact “Use this” action. It can open Campaign Studio with the source, facts, and draft goal prefilled; create a linked task; or save a clean note. The original source stays attached through the handoff.

Axis
Intelligence → action
Confidence
92%
Complexity
Medium

Basis · directThe repository already stores feed items, research responses, notes, campaigns, and tasks, but these objects remain separate at the moment a useful signal should become work.

RationaleThis closes the dashboard’s most important loop with data and screens that already exist. Each new article or research answer becomes more valuable because it can move directly into action.

DownsidesPrefill rules must stay modest. Over-inference would create confusing campaign drafts, so the first version should copy context and suggest fields rather than silently invent them.

I2

Campaign Preflight

Fast win

Add a pre-copy/export panel that checks subject length, the presence of a clear CTA and link, date consistency, reading length, missing audience context, HTML links, and accidental repetition. Keep most checks deterministic; use AI only for optional tone or audience feedback.

Axis
Campaign quality
Confidence
89%
Complexity
Low

Basis · directCampaign Studio can generate, save, copy, and export text or HTML, but it has no final check for common omissions before the content leaves the dashboard.

RationaleA short checklist prevents the most ordinary campaign mistakes without adding another workflow or external service. It also makes generated HTML safer to trust.

DownsidesHeuristics can become bossy. Checks should be advisory, explain the issue, and never block copying or export.

I3

Enrollment Moment Calendar

Planning layer

Add a lightweight calendar for enrollment deadlines, campus events, and campaign windows. Each moment can carry an audience, a 30/14/7-day nudge, and one-click actions to create a campaign or task. Start local—no Google or Outlook OAuth.

Axis
Planning & timing
Confidence
78%
Complexity
Medium

Basis · externalCurrent recruitment systems such as Salesforce Education Cloud and Slate treat events, appointments, follow-up, and actionable lists as core admissions work. 2026 enrollment-marketing guidance also calls out overlapping campaign cycles.

RationaleDates give tasks and campaigns a shared spine. A small local calendar would help the dashboard answer “what needs attention now?” without becoming a full scheduling product.

DownsidesA calendar is only useful when maintained. Keep fields minimal and add external calendar sync only if manual duplication becomes a proven annoyance.

I4

Weekly AVP Brief

Portable context

Create a one-click Markdown or HTML briefing from starred news, saved research notes, campaigns in progress, recent decisions, and open tasks. The brief can be copied into a separate ChatGPT conversation or kept as a personal weekly record.

Axis
Personal reporting
Confidence
88%
Complexity
Low

Basis · directAll of the source material already exists locally, and the intended deeper-work handoff is a separate ChatGPT session rather than a large context window inside EDMissions.

RationaleThe brief makes EDMissions’ accumulated work portable without API integrations. It also turns the dashboard into a reliable memory aid between sessions.

DownsidesAn automatic brief can become noisy. The export should begin with selected/starred material and provide a small preview before copying.

I5

Audience Lanes

Reusable context

Save a small set of reusable audience profiles—adult learners, transfers, deposited students, families, or any locally useful group. Campaign Studio applies one lane alongside campus memory and can warn when a message mixes incompatible audiences.

Axis
Reusable context
Confidence
86%
Complexity
Low

Basis · externalCurrent enrollment-marketing guidance recommends keeping overlapping deposited-student and next-class campaigns distinct. The product already has persistent campus memory, making audience memory the smallest useful next layer.

RationaleA few reusable profiles improve specificity across every campaign without storing prospect data or building segmentation infrastructure.

DownsidesProfiles can become stereotypes. Keep them editable, short, and focused on goals, barriers, proof points, and preferred CTA—not demographic assumptions.

I6

Event Follow-up Kit

Campaign mode

Add a compact Campaign Studio mode for one event. From the event name, date, audience, and CTA, generate a before-event invitation/reminder, a day-of note, an after-event follow-up, and the associated tasks.

Axis
Planning & timing
Confidence
76%
Complexity
Low

Basis · externalRecruitment platforms consistently pair event registration and visit activity with automated communication and follow-up. Campaign Studio already owns message generation and Tasks already owns the checklist.

RationaleThis packages a repeated enrollment workflow without introducing a new top-level module. It becomes stronger later if linked to the Enrollment Moment Calendar.

DownsidesIt partially overlaps the calendar idea. Build it first only if event communication is frequent enough to justify a dedicated campaign mode.
